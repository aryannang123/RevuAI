# Database Setup

## Files

- `create_searches_table.sql` - Run this in Supabase SQL Editor to create the searches table
- `add_analysis_data_column.sql` - Migration script if you need to add the analysis_data column to existing table

## Setup

1. Go to your Supabase Dashboard
2. Navigate to SQL Editor  
3. Run `create_searches_table.sql`
4. Done! The app will automatically save search history to this table.
